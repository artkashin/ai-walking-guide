# AI Walking Guide 0.3.0

Install `ai-walking-guide-0.3.0.apk` from this release's Assets; this is the APK itself, not a workflow ZIP. Android 8.0 or newer is required. This remains a debug-signed personal test build, pending physical-device acceptance.

## Что добавлено

- Постоянный плеер на всех вкладках: пауза, продолжение, остановка, реальный прогресс и перемотка в обе стороны, в том числе после паузы.
- Библиотека сохранённых рассказов и ручной повтор прослушанных/пропущенных объектов. Автоматическая память экскурсии при повторе не сбрасывается.
- Уточняющие вопросы GPT: недавние рассказы, прогресс текущего рассказа, предыдущий диалог, рекомендательные цели и свежая приблизительная позиция. Для текстового вопроса позицию можно исключить.
- Опциональный локальный голосовой режим «Окей, гид». Русская модель загружается отдельно (~45 МБ) с проверкой SHA-256. Звук ожидания и команды не отправляется в облако; в GPT идёт текст принятого вопроса с контекстом. Нового платного API нет.

## Как включить

Начните прогулку. В настройках загрузите офлайн-модель, разрешите микрофон и уведомления, затем явно включите hands-free на эту прогулку. Дождитесь статуса ожидания и скажите «Окей, гид, расскажи подробнее» или «Окей, гид, куда дальше?». Подписка ChatGPT, выбранная модель и подтверждение отключения дополнительных кредитов обязательны для запросов GPT.

Пока гид говорит, микрофон выключен: нажмите паузу в плеере/уведомлении, подождите две секунды, затем задайте вопрос. Голосовое перебивание поверх речи пока не поддерживается. Завершение прогулки выключает микрофон. Для текстового вопроса откройте «Продолжить разговор с гидом» на экране прогулки или музея; модель распознавания и микрофон для этого не нужны.

## Установка поверх старой версии

Сборки используют временную debug-подпись GitHub Actions. Если Android отказывается обновлять прежний APK из-за другой подписи, потребуется удалить старую версию и установить новую. Удаление стирает локальную историю, кэш и вход; после установки нужно снова подключить ChatGPT. Не удаляйте прежнюю версию, если её локальные данные нужно сохранить.

## Проверки и ограничения

Публикация выполняется только из main после успешных сборки/JVM/lint и Android-тестов API 26/35 для одного коммита; APK проверяется по контрольной сумме. Отдельный тест настоящей русской модели проверяет загрузку, словарь фразы и отсутствие срабатывания на тишину. Это не заменяет проверку реального произношения на телефоне.

Точность распознавания в шуме, гарнитуры/Bluetooth, работа под блокировкой на конкретном OEM, расход батареи и реальные запросы с пользовательским аккаунтом требуют проверки на телефоне. Универсальная работа в фоне и полноценный barge-in не заявлены. Подробнее: `docs/HANDS_FREE.md`, `docs/PERSISTENT_PLAYER.md`, `docs/USER_GUIDE_RU.md`.
