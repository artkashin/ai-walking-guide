Рабочая личная тестовая сборка Android 8.0+. Скачивайте **ai-walking-guide-0.2.0.apk** — распаковывать ZIP не нужно.

Реализовано:
- GPS-прогулка с уведомлением, реальные места рядом через Wikipedia и внешняя пешая навигация Google Maps без API-ключа.
- Адаптивные рекомендательные цели, независимый поиск вне маршрута, локальная память завершённых/пропущенных объектов и молчание при отсутствии подходящих фактов.
- Официальный ChatGPT OAuth + PKCE, проверка подписей, Keystore, обновление/отзыв токенов, список моделей и завершённые потоковые AI-ответы.
- Русский офлайн-голос телефона, кэш звука, пауза, продолжение и пропуск.
- Музейное фото с отдельным согласием, уменьшением/удалением EXIF и подтверждением предполагаемого произведения перед рассказом.

Проверки: 19 JVM-тестов; по 7 инструментальных тестов на API 26 и 35. APK из GitHub Actions скачан, SHA-256 и подпись проверены.

[Сборка](https://github.com/artkashin/ai-walking-guide/actions/runs/41139927009) · [Эмуляторы](https://github.com/artkashin/ai-walking-guide/actions/runs/41139924579) · [Инструкция](https://github.com/artkashin/ai-walking-guide/blob/main/docs/USER_GUIDE_RU.md)

Перед использованием установите офлайн-голос русского языка, войдите через ChatGPT и проверьте связь по подписке. Перед AI-запросами отключите дополнительные кредиты/автопокупки в ChatGPT и подтвердите это в приложении; если отключить их нельзя, AI-запросы оставьте выключенными. Приложение не покупает кредиты, не содержит API-ключей и не переключается на отдельно оплачиваемый API. Серверные настройки оплаты приложение проверить не может.

Живой вход/доступ подписки, качество голоса, работа во время настоящей прогулки и точность определения произведений требуют проверки на вашем телефоне. CI использует только синтетические данные. Не отправляйте токены, cookie, callback URL или пароли в issues.

Debug-подпись может отличаться от прежних сборок. Если Android отвергнет обновление, старую тестовую версию может потребоваться удалить; это удалит её локальные данные.
