Исправление входа ChatGPT после проверки на телефоне.

В 0.2.0 браузер показывал «Вход получен» до обмена кода и проверки токенов. Также действительный вход в профиль терялся, если сервер не предоставлял разрешение использовать подписку.

В 0.2.1:
- Успех в браузере показывается только после проверки и сохранения сеанса; есть кнопка возврата в приложение.
- Подключение профиля и доступ к подписке отображаются отдельно. Без разрешения подписки AI-запросы блокируются; есть отдельная кнопка запроса согласия.
- При возврате на экран состояние перечитывается из защищённого хранилища.
- Каждый этап входа и безопасный код ошибки видны в настройках. Коды, токены, callback URL и персональные данные не выводятся.
- Посторонний запрос браузера не поглощает одноразовый callback. Проверки подписи, state и nonce остаются обязательными; отмена не позволяет позднему ответу восстановить сеанс.

Сквозные Android-тесты используют локальный callback и тестового HTTPS-издателя с синтетическими подписанными токенами, без живого аккаунта или расхода подписки. Публикация требует успешных JVM/build/lint и API 26/35 проверок одного коммита.

После установки выполните вход снова. Если он не завершится, пришлите только короткий код и название этапа из настроек, никогда не токен или адрес callback. Фраза об успешном входе теперь отражает сохранённый проверенный сеанс; право на фактическую генерацию дополнительно проверяется отдельной кнопкой связи по подписке.

Это debug-сборка. Если Android отклонит обновление из-за другой подписи, старую тестовую версию может потребоваться удалить; это удалит её локальную историю. Не удаляйте её, если хотите сначала сохранить данные. Учётная запись ChatGPT от удаления APK не удаляется.

Дополнительные кредиты/автопокупки по-прежнему должны быть выключены в ChatGPT. Платный API, ключи, cookie или обход официальной авторизации не используются.
